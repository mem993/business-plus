# بزنس بلس — مشروع الموقع

هذه نسخة تطبيق فعلية قابلة للربط والنشر، وليست مجرد صفحة عرض. تتضمن:
- واجهة عربية متجاوبة وهوية سوداء وذهبية.
- بحث بالاسم/الوصف، وتصفية حسب المدينة والقسم.
- إنشاء حساب بالبريد وكلمة المرور وتسجيل الدخول.
- إرسال بيانات المشروع للمراجعة قبل ظهوره.
- عرض روابط واتساب وإنستغرام.
- إظهار أسعار الاشتراك: 98 ريال شهرياً و520 ريالاً لستة أشهر، مع شهر مجاني بلا بطاقة.

## ما يلزم لتشغيلها للعامة
1. إنشاء مشروع في Supabase.
2. تشغيل محتوى `supabase.sql` داخل SQL Editor.
3. نسخ Project URL و anon/public key إلى ملف `.env` (انسخي `.env.example` وسمّيه `.env`).
4. تثبيت Node.js ثم تشغيل `npm install` وبعدها `npm run dev` للتجربة.
5. رفع مجلد المشروع إلى GitHub ثم استيراده في Vercel. أضيفي متغيري البيئة نفسيهما في إعدادات Vercel.

## مهم قبل استقبال الجمهور
- حالياً لا يوجد ربط دفع أو سحب تلقائي للبطاقات. لا تجمعي بيانات البطاقات بنفسك. نضيف مزود دفع مرخصاً بعد اختيار المزود واستكمال متطلبات النشاط.
- اعتماد المشاريع وإدارة الاشتراكات يحتاجان لوحة إدارة آمنة؛ في هذه النسخة موافقة النشر تتم من لوحة Supabase يدوياً بتغيير `approved` إلى `true` بعد التحقق.
- رابط الصورة في النموذج حالياً رابط صورة عام؛ نضيف رفع الصور إلى Storage في خطوة لاحقة.
- لا تضعي مفاتيح سرية أو مفاتيح `service_role` في الواجهة أو GitHub. استخدمي anon/public key فقط في المتصفح.
- البريد `hello@businessplus.example` في التذييل نص تجريبي ويجب تغييره إلى بريد تملكينه.

## قواعد التسعير المعتمدة في الواجهة
- أول 30 يوماً مجانية دون طلب بطاقة.
- بعد انتهاء التجربة، يختار صاحب المشروع الاشتراك ويوافق صراحة على التجديد التلقائي عند إدخال وسيلة الدفع.
- الشهري 98 ريالاً، و6 أشهر 520 ريالاً.
